MONDO DI GINNY - VERSIONE 2 - PROTOTIPO MILO

1. Apri github.com/bushino87/mondo-di-ginny
2. Add file > Upload files
3. Carica i file di questa cartella (index.html, sw.js, manifest.webmanifest e cartella icons) nella radice del repository. Sovrascrivi i file esistenti.
4. Commit changes. Attendi che GitHub Pages pubblichi il commit.
5. Su iPad apri https://bushino87.github.io/mondo-di-ginny/ e ricarica; apri Animali > Milo · Novita.
6. Se la versione installata mostra ancora quella precedente, chiudi e riapri l’app dopo aver aperto il sito in Safari; eventualmente ricarica il sito in Safari.
